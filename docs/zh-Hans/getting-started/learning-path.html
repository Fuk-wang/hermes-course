学习路径

Hermes Agent 功能丰富——CLI 助手、Telegram/Discord 机器人、任务自动化、强化学习训练等。本页帮助您根据自身经验水平和目标，确定从哪里开始、阅读哪些内容。

从这里开始

如果您尚未安装 Hermes Agent，请先阅读安装指南，然后完成快速入门。以下内容均假设您已完成安装。

如何使用本页

  • 已知自己的水平？ 跳转至按经验水平表格，按照对应层级的阅读顺序进行。
  • 有明确目标？ 跳至按使用场景，找到匹配的场景。
  • 随便浏览？ 查看主要功能表格，快速了解 Hermes Agent 的全部能力。

按经验水平

水平 目标 推荐阅读 预计时间
初级 快速上手，进行基本对话，使用内置工具 安装 → 快速入门 → CLI 用法 → 配置 约 1 小时
中级 搭建消息机器人，使用记忆、cron 任务、技能等高级功能 会话 → 消息 → 工具 → 技能 → 记忆 → Cron 约 2–3 小时
高级 构建自定义工具、创建技能、使用强化学习训练模型、参与项目贡献 架构 → 添加工具 → 创建技能 → 贡献指南 约 4–6 小时

下一步阅读

根据您当前所处阶段：

  • 刚完成安装？ → 前往快速入门，运行您的第一次对话。
  • 完成了快速入门？ → 阅读 CLI 用法和配置，自定义您的设置。
  • 已熟悉基础？ → 探索工具、技能和记忆，释放 agent 的全部能力。
  • 为团队部署？ → 阅读安全和会话，了解访问控制与对话管理。
  • 准备好开发了？ → 进入开发者指南，了解内部机制并开始贡献。
  • 想要实际示例？ → 查看指南部分，获取真实项目案例和技巧。
