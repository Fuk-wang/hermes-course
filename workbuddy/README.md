# Workbuddy.homes 展示站 · 站内说明

单页产品展示站，整个站点就是根目录这一个 `index.html`：样式、图标（内联 SVG）、
交互脚本全部写在里面，不引用 CDN、外部字体和外部图片。双击就能离线打开。

本地打开
-----------------------------------------------------
- 直接双击 index.html（file:// 打开也完全正常，这是设计场景）
- 想在 http 下预览：在本目录跑 `python -m http.server 8942 --bind 127.0.0.1`，
  然后访问 http://127.0.0.1:8942/index.html

页面结构（对应需求清单）
-----------------------------------------------------
1. 顶部固定导航：首页 / 功能特性 / IMA知识库教程 / 使用指南 / 开发者文档，点击平滑滚动 + 当前板块高亮
2. 首屏英雄区：主标题、副标题、主按钮「立即开始使用」（悬停放大变色）、右侧纯 CSS 桌面窗口示意图
3. 功能特性：4 张卡片（多模型兼容 / 双入口模式 / 跨平台支持 / 内置扩展组件），悬停上浮加深阴影
4. 核心功能 IMA 知识库对接：前置条件 → 操作步骤 → 效果说明，三个 tab 切换带过渡动画
5. 使用指南：左 GUI、右 CLI 分栏；CLI 代码块带「一键复制」按钮，复制后按钮变「已复制」并弹出提示
6. 开发者文档：5 条 CLI 命令（chat / ask / kb attach / model / ext），点标题折叠展开，含参数表
7. 页脚：项目名、版权（年份脚本自动取当前年）、页面导航与说明

改法
-----------------------------------------------------
- 文案、卡片、命令参数都在 `index.html` 里，按注释小节改即可（样式在 `:root`
  设计变量里统一控制：深灰 `--gray` 系 + 蓝绿 `--teal` 系）。
- 改完 commit + push，几十秒后线上自动更新；浏览器可能还显示旧版，Ctrl+F5 强刷。

已实测（本机无头 Chrome，2026-10-13）
-----------------------------------------------------

注意
-----------------------------------------------------
