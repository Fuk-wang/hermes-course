    Installation

    安装
    学生需要学会

    安装 Hermes Agent，了解基本安装方式。

    验收方式

    hermes 能正常启动。

    官方文档 docs/getting-started/installation.html
  2. 2

    Quickstart

    快速上手
    学生需要学会

    完成初始化、模型配置和第一次对话。

    验收方式

    能正常与 Hermes 对话。

    官方文档 docs/zh-Hans/getting-started/quickstart.html
  3. 3

    Providers / Model Configuration

    模型配置
    学生需要学会

    理解 Provider、Model、Base URL、API Key 的关系；学会配置模型。

    验收方式

    能成功配置教师提供的模型 API。

    官方文档 docs/integrations/providers.html
  4. 4

    CLI

    命令行
    学生需要学会

    学会使用 /help、/model、/tools、/status、/context。

    验收方式

    能说出当前模型、可用工具和 Context 情况。

    官方文档 docs/zh-Hans/user-guide/cli.html
  5. 5

    Configuration

    配置文件
    学生需要学会

    找到并理解 ~/.hermes/config.yaml、.env 等配置文件。

    验收方式

    能解释普通配置和 Secret 配置的区别。

    官方文档 docs/zh-Hans/user-guide/configuration.html
  6. 6

    Tools

    工具调用
    学生需要学会

    理解 Hermes 如何调用文件、Terminal 等工具完成真实任务。

    验收方式

    完成一次读取文件、处理数据并生成结果文件的 Tool Calling。

    官方文档 docs/zh-Hans/user-guide/features/tools.html
